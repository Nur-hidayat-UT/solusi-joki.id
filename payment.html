Petunjuk Pembayaran

1. Cara Transfer via Dana:

  1. 1. Buka aplikasi Dana di smartphone Anda
  2. 2. Pilih menu "Transfer" → "Transfer Dana" atau "Kirim ke Dana"
  3. 3. Masukkan nomor Dana penerima: 083153145931
  4. 4. Isikan nominal sesuai perkiraan biaya yang disepakati
  5. 5. Masukkan PIN Dana dan tunggu konfirmasi (biasanya 1-2 menit)
  6. 6. Screenshot bukti transfer dan kirim ke admin via WhatsApp

2. Cara Transfer via BRI:

  1. 1. Buka aplikasi BRI Mobile atau datang ke ATM BRI
  2. 2. Pilih menu "Transfer" → "Transfer ke Rekening BRI"
  3. 3. Masukkan nomor rekening BRI: 4782456127945
  4. 4. Nama penerima akan muncul di layar - pastikan sesuai
  5. 5. Isikan nominal pembayaran sesuai kesepakatan
  6. 6. Konfirmasi dan masukkan PIN/kartu ATM Anda
  7. 7. Catat nomor referensi transfer dan konfirmasi ke admin

info Catatan Penting

  • ✓ Konfirmasi pembayaran secara real-time untuk mempercepat proses pengerjaan
  • ✓ Jika transfer via BRI, biaya admin ditanggung pengirim/penerima sesuai bank
  • ✓ Simpan bukti transfer untuk keperluan verifikasi
  • ✓ Hubungi admin via WhatsApp jika ada kendala atau pertanyaan
  • ✓ Untuk pembayaran nanti, Anda dapat menghubungi admin untuk mengatur jadwal pembayaran yang sesuai
